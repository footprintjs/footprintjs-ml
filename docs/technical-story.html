FOOTPRINT / ML · BEFORE THE STORY

Can FootPrint’s flowchart pattern work in ML?

Training changes the numbers a model uses to predict. Validation checks those predictions on separate examples. A release chooses which model an application will use.

We tested wrong checkpoints, contaminated validation data and interrupted training. We then checked candidate selection, checkpoint handoff and retrying a local release after a lost reply.

The ML trainer

Learns and predicts

Rust, scikit-learn or JAX holds the arrays and computes updates and predictions.

FootPrint + ML layer

Tracks what changed

Stages pass model references and validation results. Explicit guards check data, selection and the checkpoint handed to a publisher.

Lens + foottrace

Explains the saved run

Inspect which model changed, what validated it, and how a release or retry was decided.
