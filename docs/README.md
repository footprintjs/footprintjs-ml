## Hosting

This is a static site with relative links, so it can live at a GitHub Pages project subpath such as stories/ml/. The two HTML views carry their scripts, styles and diagrams inline. Keep the evidence folder and supporting files beside them. No trainer, server API, external script or network service is required to view it.

## Evidence and limits

The [evidence ledger](EVIDENCE.md) distinguishes original retained-source hashes from public-copy hashes. Personal local paths were projected in metadata and 13 evidence JSON copies; 6 guide copies link to repository documents. Model IDs, logical evidence digests and numerical values remain original recorded facts; the [publication manifest](publication-manifest.json) separately checks the public files. It does not authenticate a run.

These are controlled local examples of orchestration, model/evaluation identity, data-use and release checks. Numerical tools perform training and determine accuracy. The crash recovery helpers remain example-owned, release/retry proofs are local, and an independent human debugging advantage over complete structured logs has not been established. The story does not execute training.
